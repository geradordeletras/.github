# Gerador de Letras

🎨 **Free fancy-text generator** — style text for Instagram, TikTok, Free Fire and Discord bios and nicknames right in the browser. No install needed, one-tap copy.

## What is it?

Gerador de Letras is a 100% free online tool that converts plain text into stylish, decorative fonts using Unicode characters. Perfect for:

- 📸 Instagram bios and captions
- 🎵 TikTok profiles and video descriptions
- 🎮 Free Fire nicknames
- 💬 Discord usernames and messages

## Features

- ✅ 100% free, no sign-up required
- 📱 Works on mobile — no app install needed
- 👆 One-tap copy to clipboard
- 🎭 Dozens of unique text styles
